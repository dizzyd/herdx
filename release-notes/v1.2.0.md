## Clickable web links

Hold **⌘** over a link in a pane and it underlines, with its destination in a
tooltip. **⌘-click** opens it in your browser.

| | |
| --- | --- |
| **⌘** held | Underline the link under the pointer and show where it goes |
| **⌘-click** | Open it in the default browser |

Both kinds of link work: an OSC 8 hyperlink, where a program labels some text
with a target, and a plain URL printed as text. Where both are present the OSC 8
target wins, since that is the one the program meant. A URL that wrapped onto the
next row opens the whole address rather than the part on the row you clicked.

Only `http` and `https` open. A gesture that is dragged, moved off the link, or
outlived by its surface or machine opens nothing — and is still consumed whole,
so a program using mouse reporting never sees half a click.

Contributed by [Jason Wilder](https://github.com/jwilder), the first
contribution to HerdX from outside.

## Telling two agents apart

The agents list now says *where* each agent is, and only when that answers
something. A workspace holding one agent gets no bracket — its name has already
said everything there is to say. Where a workspace holds several, the row names
what differs between them: the pane's name if you gave it one, the tab it sits in
when that tells it from the others, and otherwise its number carrying whatever is
running there — `root (claude 2)`.

Workspace rows name the tab they would open at, when somebody named it.
`herdx (claude)` is worth the width in a 240pt sidebar; `crucibulum (1)` says
nothing that `crucibulum` did not, so a tab herdr still calls by its number is
left off.

Renaming a tab or a pane now shows up in the sidebar straight away.

## Worth knowing

- **herdr does not mark soft wraps**, so a printed URL is followed onto the next
  row whenever a row's text runs to the pane's edge. A line that merely happens
  to end at the edge can have the next one joined onto it. The underline spans
  every row it would open and the tooltip carries the full address, so what you
  are about to open is on screen before you click.
- **A pane is numbered by its id**, the `2` of `w1:p2`, so it keeps meaning the
  same pane after one beside it closes.
- **Hibernated rows carry no bracket.** One of those stands for a whole
  workspace, so it has nothing to tell apart.
