## Select All can be dismissed again

After **Select All** over a program that handles the mouse itself — an agent,
an editor, a pager — the highlight stayed until you closed the pane, because
clicks went to the program and nothing else cleared it. Typing, pasting or
clicking into the pane now dismisses the selection, and leaves copy mode if it
was on. Scrolling and right-clicking still leave it alone, so you can scroll
through history with a selection standing.
