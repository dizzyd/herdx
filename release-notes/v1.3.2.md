## A theme for light and one for dark

Settings ▸ Appearance is now **Light**, **Dark** or **Follow System**. Pinned to
one, there is a single theme to choose; following the system, there is a theme
for light and one for dark, and the terminal changes with the system.

**Choose…** beside a theme opens the theme list, which previews each palette on
the terminal as you move through it — including the dark theme while the system
is light. The list always starts with the built-in palette and ends with
**Load from File…**, so neither waits on downloading kitty's collection.

The separate Terminal appearance, the background and text colour wells and
Match Attached Terminal are gone. A theme you had loaded carries over into both
appearances, with any colours you had set on it, so nothing changes on screen
when you upgrade.

## The window no longer changes colour with what is in a pane

The window's frame followed whichever colour covered most of a pane. A diff, or
an agent's tool output scrolled to fill a pane, could turn the title bar,
sidebar and tabs red or green. The window now takes its colours from your theme
alone, and a pane's padding follows the cells along its edge — so a program that
paints its own background still fills its pane, and a highlighted line runs to
the edge.

## Settings, tidied

Settings is arranged in sections — Text, Appearance, Panes, Agents — with each
label level with its control and each note beside the control it explains. A
long theme name no longer widens the window.
