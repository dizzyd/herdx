## Hibernate idle workspaces

Ends the processes of a local workspace you have stopped using, and keeps what
its agents were talking about. The workspace stays in the sidebar, dimmed, in a
**Hibernated** band under the agents list. Click it and the whole thing comes
back — same tabs, same splits and ratios, same working directories, each agent
resumed into its own conversation.

| | |
| --- | --- |
| **⌃B ⌘H** | Hibernate the focused workspace now |
| **Settings → Hibernate** | Sweep workspaces idle for 4–24 hours. Off by default |

It would rather do nothing than guess. A workspace is left alone while an agent
is working or blocked, while anything is running in a pane that has no agent in
it — a build, a dev server, a REPL — if an agent has no session to resume into,
or if it has only been quiet since HerdX started, which is unknown rather than
old. ⌃B ⌘H tells you which of those it was, so you know what to close first.

Resuming uses herdr's own resume flags, so it covers the agents herdr can
resume: claude, codex, cursor, copilot, opencode, qwen, droid, grok, and the
rest of the eighteen.

## New local workspace

**⌃B ⌘N** opens a workspace on this Mac from wherever you happen to be looking,
including from a remote machine — herdr's `new_workspace` lands where the focus
already is, which is the one thing it cannot give you. Also in the Shell menu.

## Worth knowing

- **Local only.** A remote machine is reached over herdr's client-shell
  transport, which does not carry the methods hibernation needs.
- **A hibernated workspace is gone from herdr, not suspended inside it.** It
  exists as a row in HerdX and in `~/Library/Application Support/HerdX`, so a
  herdr TUI attached to the same session will not show it.
- **An agent you started but never spoke to has no conversation on disk yet**,
  so it comes back at the session picker rather than in a conversation.
