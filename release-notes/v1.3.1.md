## Remote machines connect when HerdX is opened from the Finder

Opened from the Finder, the Dock or Launchpad, HerdX was handed the system's
default ssh agent rather than the one your shell uses. If your keys live in
1Password, Secretive or gpg-agent and a shell profile points `SSH_AUTH_SOCK` at
it, every remote machine refused the connection with **Permission denied
(publickey)**, even though the same `ssh` worked from a terminal.

HerdX now asks your login shell which agent it uses, and connects with that.
